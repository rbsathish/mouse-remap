Documentation release: **the app behaves exactly as in 1.0.0.** The only changes are the version number and the README and changelog bundled in the download, which now say clearly what the app was tested on.

## What the README now says

- **Tested on one mouse:** the Amazon Basics Pro Series 2.4G + Bluetooth + USB Triple Mode Wireless Ergonomic Mouse (9 buttons, black), connected through its USB receiver or cable (Windows lists it as USB device `3151:5031`), on Windows 11. Bluetooth mode, other mice and Windows 10 have not been tested.
- A **compatibility table**: the five standard buttons should work on other mice; the three top buttons (Search, Screenshot, Desktop) only work on mice built like this one; extra gaming-mouse buttons are not supported; maker software can conflict if it remaps the same button.
- Independent project, not affiliated with or endorsed by Amazon.

## Download

`MouseRemap-1.0.1-win64.zip`: unzip, run `MouseRemap.exe`, pick your actions, click **Apply and save**. Check the download against the `.sha256` file if you like. If you already run 1.0.0 there is no need to update.

The exe is not code-signed, so Windows SmartScreen may warn about an unknown publisher; the source and build steps are in the repository.
