New in this version: the app now shows the mouse's **DPI level**.

## What's new

- **DPI level display.** The settings window and the tray icon's tooltip show the mouse's DPI level (1, 2, 3 ...) and update each time you press the mouse's DPI button.
- It only listens to the mouse. Nothing is sent to it, so the app cannot change your DPI.
- It shows the mouse's own level number, not a DPI value such as 1600, and it can't know the level at startup, only after the first press of the DPI button.
- Tested on the one mouse listed in the README (Amazon Basics Pro Series Triple Mode), through its receiver or cable. In Bluetooth mode, or with other mice, the window says the level is not available.

- **Clipboard history** (Win+V) is now in the preset list, so you can put it on a button such as the wheel click.

Not included, because the mouse doesn't expose them to Windows: battery percentage, the actual DPI value, setting the DPI, and switching connection mode.

Everything else works as in 1.0.1. Settings are kept when you update.

## Download

`MouseRemap-1.1.0-win64.zip`: unzip, run `MouseRemap.exe`. If you already run an earlier version, quit it from the tray first, then replace the exe. Check the download against the `.sha256` file if you like.

The exe is not code-signed, so Windows SmartScreen may warn about an unknown publisher; the source and build steps are in the repository.
