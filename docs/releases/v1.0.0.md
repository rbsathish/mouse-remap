First release of **Mouse Button Remap**: choose what the extra buttons on your mouse do.

## Highlights

- Remap **left, right, middle, back and forward** to key combinations (Copy, Paste, Undo, Close tab, media keys, or anything you type), or leave them normal.
- Remap the three **top buttons** (Search, Screenshot, Desktop) of the Amazon Basics Pro Series triple-mode mouse. Your keyboard's own Win+D and Print Screen keep working.
- Works over 2.4G, Bluetooth or USB: it acts on what Windows receives. No driver, no account, no internet.
- Tray icon, optional start with Windows, single instance, and a safety net so left/right can't lock you out.

## Download

`MouseRemap-1.0.0-win64.zip`: unzip, run `MouseRemap.exe`, pick your actions, click **Apply and save**. Check the download against the `.sha256` file if you like.

The exe is not code-signed, so Windows SmartScreen may warn about an unknown publisher; the source and build steps are in the repository.

## Good to know

- The Screenshot (top) button acts when you release it (needed to tell it apart from your keyboard's Print Screen).
- Buttons handled inside the mouse (DPI switch, mode switch) can't be remapped.
- **Tested on one mouse:** the Amazon Basics Pro Series 2.4G + Bluetooth + USB Triple Mode Wireless Ergonomic Mouse (9 buttons, black), connected through its USB receiver or cable (Windows lists it as USB device `3151:5031`), on Windows 11. Bluetooth mode, other mice and Windows 10 have not been tested.
- The five standard buttons should work on other mice; the three top buttons only work on mice built like this one; extra gaming-mouse buttons are not supported. See [Compatibility](../../README.md#compatibility).
